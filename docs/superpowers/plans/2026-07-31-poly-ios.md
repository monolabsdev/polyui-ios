# Poly iOS Client Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Expo SDK 57 starter into a native-feeling Poly iOS client shell with SwiftUI chrome, a conversation surface, pairing flow, local boundaries, and typed foundation services.

**Architecture:** Expo Router owns route entry points. iOS component files outside `src/app` own `@expo/ui/swift-ui` trees; React Native appears only inside `RNHostView` for Markdown and Camera. Zustand owns local UI state, React Query owns remote agent state, Zod validates protocol payloads, SQLite caches conversations, SecureStore owns device secrets.

**Tech Stack:** Expo SDK 57, Expo Router, `@expo/ui/swift-ui`, TypeScript, React Query, Zustand, Zod, Expo Secure Store, Notifications, Camera, Crypto, SQLite, File System, Image, Haptics, Local Authentication, Linking, Network, React Native Markdown Display, `@noble/*`.

## Global Constraints

- Use Expo SDK 57 and versioned Expo docs at `https://docs.expo.dev/versions/v57.0.0/`.
- All iOS application chrome uses Expo UI SwiftUI components.
- Keep platform-specific SwiftUI files outside `src/app`.
- Use native `fetch`, no Axios; use Expo Secure Store for secrets, never AsyncStorage.
- Keep remote protocol, networking, state, persistence, cryptography, and UI separated.
- No NativeWind, Tailwind, Paper, NativeBase, MUI, or replacement UI framework.
- Use Dynamic Type, native SF Symbols, native lists/forms/sheets/menus, and accessible labels.

## File Map

- Modify `src/app/_layout.tsx`: providers and notification bootstrap.
- Modify `src/app/index.tsx`: route to native home component.
- Create `src/app/settings.tsx`, `src/app/pairing.tsx`: Router routes.
- Modify `src/components/home-screen.ios.tsx`: native workspace, chat, activity, and settings entry shell.
- Create `src/components/settings-screen.ios.tsx`: native settings form.
- Create `src/components/pairing-screen.ios.tsx`: native pairing sheet/route.
- Create `src/components/pairing-camera.tsx`: Camera-only QR capture surface.
- Create `src/components/markdown-message.tsx`: RN Markdown island hosted by SwiftUI.
- Create `src/domain/poly.ts`: Zod schemas and domain types.
- Create `src/state/app-store.ts`: minimal Zustand state.
- Create `src/data/agents.ts`: fetch and validate remote agents with local fallback.
- Create `src/data/conversation-cache.ts`: SQLite migration and message cache.
- Create `src/security/device-identity.ts`: SecureStore-backed device identity.
- Create `src/security/session-crypto.ts`: X25519 session keys and XChaCha20-Poly1305 message encryption.
- Create `src/network/poly-socket.ts`: reconnecting native WebSocket boundary.
- Create `src/services/notifications.ts`: permission and notification category setup.
- Modify `app.json`: camera and notification configuration.
- Modify `package.json` and `bun.lock`: remove forbidden unused UI/storage dependencies and add a domain check script.
- Create `scripts/verify-domain.ts`: one runnable schema self-check.
